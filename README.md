Entry for the make.fun competition [Sorry, I Heard That Wrong](https://make.fun/competitions/u-kiencx-sorry-i-heard-that-wrong-1858c729): the funniest one-line apology a smart speaker gives after mishearing its owner.

## The line

> I heard 'set a timer for pasta' as 'set a timer for panic'. Both are now running. The pasta is fine. You are not.

(113 characters — within the 140-character limit.)

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed). Standard library only — no third-party packages.
